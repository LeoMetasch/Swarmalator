Experiment 1: Critical Exponent of the Order Parameter ($\beta$)Objective: Determine the critical exponent $\beta$ governing the phase transition from the Static Async state to the Active/Splintered Phase Wave state.Theoretical Basis:Near the critical point $K_c$, the order parameter $S$ is expected to follow the power law relationship:$$S \sim |K - K_c|^\beta$$In mean-field Kuramoto models, $\beta = 0.5$. The goal is to determine if the spatial coupling in the swarmalator model shifts this exponent.Input Requirements:Fixed Parameters: $N$ (e.g., 800 or 1000), $J$ (e.g., 0.5).Variable Parameter: $K$ (fine-grained sweep with increments $\Delta K = 0.001$ or smaller).Data: Time-averaged order parameter $S = \max(S_+, S_-)$ for each $K$.+1Execution Steps:Locate $K_c$: Calculate the second derivative of $S$ with respect to $K$ ($d^2S/dK^2$). Identify the peak of this derivative to define the precise numerical critical point $K_c$. (Note: Theoretical approximation is $K_c \approx -1.2J$ ).+1Filter Data: Select data points strictly in the ordered phase ($K < K_c$) but close to the transition (e.g., $10^{-3} < |K - K_c| < 10^{-1}$).Log-Log Transformation: Compute $X = \log(|K - K_c|)$ and $Y = \log(S)$.Linear Regression: Perform a linear fit on the transformed data ($Y = \beta X + C$).Validation: Calculate the $R^2$ value to verify the goodness of fit.Deliverables:Computed value of $\beta$.Log-log plot of $S$ vs. $|K - K_c|$ with the fitted line.
Experiment 2: Finite Size Scaling (FSS)Objective: Verify the nature of the phase transition and extract critical exponents $\nu$ (correlation length exponent) and $\gamma$ (susceptibility exponent) by analyzing system size dependence.Theoretical Basis:Phase transitions are only sharp in the thermodynamic limit ($N \to \infty$). In finite systems, the "susceptibility" (variance of the order parameter) scales as $\chi_{max} \sim N^{\gamma/\nu}$. The order parameter curves should collapse onto a universal function:$$S(K, N) = N^{-\beta/\nu} \tilde{S}((K-K_c)N^{1/\nu})$$Input Requirements:Variable Parameter: System size $N$ (e.g., 100, 200, 400, 800, 1600).Sweep: Detailed $K$ sweep across the critical region for each $N$.Execution Steps:Generate Ensemble Data: Run the simulation for multiple values of $N$. For each $N$, perform the fine-grained $K$ sweep.Calculate Susceptibility: For each $N$, compute the proxy for susceptibility $\chi = N \cdot \text{var}(S)$ (fluctuation of the order parameter over time).Peak Analysis: Identify the maximum susceptibility $\chi_{max}(N)$ for each population size.Scaling Exponents:Fit $\log(\chi_{max})$ vs. $\log(N)$ to find the ratio $\gamma/\nu$.Fit $\log(S_{max})$ at $K_c$ vs. $\log(N)$ to find $-\beta/\nu$.Data Collapse: Use numerical optimization (e.g., Python scipy.optimize) to find the exact $\nu$ and $\beta$ values that minimize the variance between the scaled curves.Deliverables:Values for exponents $\nu$ and $\gamma$.Plot of raw $S$ vs. $K$ curves for different $N$."Data Collapse" plot showing all curves overlaying onto a single master curve.
Experiment 3: Critical Slowing Down (Dynamic Scaling)Objective: Investigate the divergence of relaxation times near the critical point to determine the dynamic critical exponent $z$.Theoretical Basis:As a system approaches a critical point, the restoring forces vanish, causing the system to recover from perturbations increasingly slowly (critical slowing down). The relaxation time $\tau$ scales as:$$\tau \sim |K - K_c|^{-z\nu}$$This is particularly relevant given the observation of "long transients" in the Splintered Phase Wave state.Input Requirements:Fixed Parameters: $N$, $J$.Variable Parameter: $K$ (values approaching $K_c$ from the disordered/Static Async side).Initial Conditions: Disordered state (random positions/phases).Execution Steps:Sampling Near Criticality: Select 10-20 values of $K$ approaching $K_c$ from the stable side (where the system is expected to eventually reach a steady state).Time Series Analysis: For each run, record the time series of the order parameter $S(t)$.Extract Relaxation Time ($\tau$): Fit the decay of the order parameter (or the envelope of its fluctuations) to an exponential function $S(t) \sim e^{-t/\tau}$. Alternatively, measure the time required for $S(t)$ to reach a stationary value.Log-Log Analysis: Plot $\log(\tau)$ vs. $\log(|K - K_c|)$.Exponent Calculation: The slope of this line corresponds to $-z\nu$.Deliverables:Computed value of the dynamic exponent product $z\nu$.Plot of relaxation time $\tau$ as a function of distance from criticality.
